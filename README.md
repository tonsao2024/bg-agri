# งบประมาณกระทรวงเกษตรและสหกรณ์ 2569

Static dashboard สำหรับสำรวจงบประมาณรายจ่ายของกระทรวงเกษตรและสหกรณ์ ปีงบประมาณ 2569 โดยไม่มี backend: GitHub Pages เปิดได้จากไฟล์ใน repository โดยตรง

> **ข้อควรทราบ:** ข้อมูลนี้คือ *งบที่ตั้งไว้* ไม่ใช่ยอดเบิกจ่ายจริง และมิติจังหวัดเกิดจากการสกัดข้อความใน `ITEM_DESCRIPTION` จึงไม่ควรตีความว่าเป็นการจัดสรรเชิงพื้นที่ทั้งหมดของกระทรวง

## สิ่งที่ dashboard วิเคราะห์

- **ภาพรวม:** งบตามหน่วยงาน หมวดรายจ่าย และรายการงบสูงสุด
- **โครงสร้าง:** แผนงาน → ผลผลิต/โครงการ, treemap หน่วยงาน → หมวด → รายการ, heatmap หน่วยงาน × หมวด
- **พื้นที่:** จังหวัด ภาค และสัดส่วนวงเงินที่ระบุพื้นที่ได้
- **ภาระผูกพัน:** แยกปีงบ 2569 ออกจากรายการข้ามปีอย่างชัดเจน แล้วแปลงปี ค.ศ. เป็น พ.ศ.
- **ความเสี่ยง:** HHI, Top-10 share, Pareto 80%, Gini จังหวัด, ค่าเฉลี่ยเทียบค่ากลาง และงบก้อนรวม
- **การใช้งาน:** ทุกตัวกรองอยู่ใน URL hash เพื่อแชร์มุมมองเดิมได้ และดาวน์โหลด CSV ตามตัวกรองได้

## เริ่มใช้งานข้อมูลจริง

1. วางไฟล์ดิบที่ `data/Agr_Budget-2569.csv`
2. ติดตั้ง dependency สำหรับเตรียมข้อมูล (ครั้งแรกเท่านั้น)

   ```bash
   python -m pip install -r tools/requirements.txt
   ```

3. สร้าง JSON สำหรับ browser

   ```bash
   python tools/prepare_data.py
   ```

   สคริปต์จะหยุดหากยอด `FY2569 total` ไม่เท่ากับ `130111038700.0` บาท เพื่อกันการปะปนของปี ค.ศ. ในตารางภาระผูกพัน

   ตัวอย่างผลลัพธ์ที่ต้องได้:

   ```text
   rows: 5,384
   FY2569 total: 130111038700.0
   ```

   หากเป็นไฟล์ฉบับปรับปรุงและตั้งใจยอมรับยอดใหม่ ให้ตรวจสอบไฟล์ก่อน แล้วค่อยใช้ `--skip-total-check`

   ```bash
   python tools/prepare_data.py --skip-total-check
   ```

4. เปิด local server (ห้ามเปิด `index.html` ตรง ๆ เพราะ browser จะ block `fetch`)

   ```bash
   python -m http.server 8000
   ```

   จากนั้นเข้า `http://localhost:8000`

### แผนที่จังหวัด (ไม่บังคับ)

วาง GeoJSON ระดับจังหวัดที่ `data/thailand.geojson` แล้ว refresh หน้าเว็บ ตัวเว็บจะจับคู่ชื่อจังหวัดไทยกับ property ที่พบบ่อย เช่น `NAME_1`, `NAME_TH`, `name`, `province` และรองรับชื่ออังกฤษมาตรฐาน 77 จังหวัดโดยอัตโนมัติ ถ้าไม่มีไฟล์นี้ dashboard ส่วนอื่นยังทำงานครบ และจะแจ้งสถานะในกล่องแผนที่แทน

## ตรวจสอบตัวเลขสำคัญหลังสร้าง JSON

- งบปี 2569: **130,111,038,700 บาท** (4,274 รายการ)
- กรมชลประทาน: ประมาณ **87,808 ล้านบาท** หรือ **67.49%**
- งบลงทุน: ประมาณ **92,565 ล้านบาท** หรือ **71.1%**
- สคริปต์เก็บรายการข้ามปีแยก `YEAR_TYPE` เป็น `ผูกพันปีก่อนหน้า` และ `ผูกพันปีถัดไป` ไม่บวกรวมกับงบปี 2569 โดยค่าเริ่มต้น

## Deploy GitHub Pages

1. Commit ไฟล์ dashboard พร้อม `data/budget.json` ที่สร้างเสร็จแล้ว (และ `data/thailand.geojson` ถ้าจะใช้แผนที่)
2. GitHub repository → **Settings** → **Pages**
3. Source: **Deploy from a branch** → เลือก branch ที่เผยแพร่ และ folder **/ (root)**
4. บันทึก แล้วเปิด URL ที่ GitHub แสดง

ทุก path ในหน้าเว็บเป็น relative เช่น `data/budget.json` ไม่ใช้ `/data/budget.json` จึงทำงานได้เมื่อ Pages อยู่ใต้ subpath ของ repository และมี `.nojekyll` ที่ root แล้ว

## แหล่งที่มาและวิธีอ่าน

- ไฟล์ต้นทาง: งบประมาณรายจ่าย กระทรวงเกษตรและสหกรณ์ ปี 2569
- วันที่ประมวลผลจะแสดงจาก `meta.prepared_at` ใน `budget.json`
- `DELIVERABLE` สร้างจาก `COALESCE(PROJECT, OUTPUT)` เพื่อไม่ให้การ drill-down ตกหล่น
- จังหวัด/อำเภอ/ตำบลเป็นการ extract ด้วย rule-based pattern จาก `ITEM_DESCRIPTION`; รายการส่วนกลางหรือรายการที่ไม่สะกดคำว่า “จังหวัด” จะไม่ปรากฏในมิติพื้นที่
